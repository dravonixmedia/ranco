# Project portfolio. One folder per project, see MEDIA_GUIDE.md

Copy the _example-project folder, rename it, add photos to cover/ and gallery/, then fill in project.json.

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
