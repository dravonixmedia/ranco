# Homepage, About RANCO

One strong architectural photograph, shown portrait (4:5) on large screens and landscape on phones. At least 1600 px on the long side. The first file is used. While empty, the 3rd hero photo is used.

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
