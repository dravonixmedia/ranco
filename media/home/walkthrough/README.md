# Chapter 04, Your Home (exhibition walkthrough)

Up to six landscape photographs (4:3 works best), 2000 px wide or larger, hung as plates in a gallery hall. While empty, the hero photos are used; the plates are captioned "Illustrative photography".

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
