# Floating gallery ("A home begins long before the foundation")

Up to seven photographs of Kerala homes: exteriors, verandahs, interiors, light. Mixed landscape and portrait, at least 1600 px on the long side. The first file is the one that opens to fill the screen. While empty, the hero photos are used. Never add photos of work that is not RANCO's unless they are clearly general imagery.

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
