# From Idea to Handover (the home-building journey)

Up to six photographs, one per stage, in this order:
01- your idea (for example a conversation or sketch), 02- planning and design, 03- drawings, 04- construction on site, 05- finishing details, 06- the completed home.

A stage without a photo is shown as text only in production (and as a labelled placeholder in the preview). Landscape 4:3, at least 1600 px wide. Only photographs RANCO has the right to use; site photos must not identify a client without permission.

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
