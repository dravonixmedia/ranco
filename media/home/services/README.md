# Homepage, What We Do

Used only when the confirmed service has no photo in `media/services/<service>/`. Landscape 3:2, at least 2000 px wide. The first file is used.

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
