# Heritage Home Renovation

Photographs for the Heritage Home Renovation service: traditional Kerala homes, tiled roofs, timber pillars and detailing, verandahs and, where appropriate, nalukettu courtyards. Portrait 4:5 works best, at least 1600 px tall. The first file is the main image; the second, if present, is a smaller detail.

No European, Mediterranean or Gulf-style houses. Only photographs RANCO has the right to use.

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
