# New Home Construction

Photographs for the New Home Construction service: contemporary Kerala homes, natural light, clean forms and warm materials. Landscape 3:2, at least 2000 px wide. The first file is the main image; the second, if present, is a smaller detail.

Only photographs RANCO has the right to use. Do not present them as completed RANCO projects (projects go in media/projects/).

Supported: .jpg .jpeg .png .webp .avif. Files are used in name order (01-, 02-, …).
Add alt text in `images.json` in this folder. See `MEDIA_GUIDE.md` at the repository root.
